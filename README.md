## Publish free with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.

This is a static contact/landing page; job applications are sent as WhatsApp messages and email links. It does not promise jobs or automatically store candidate information.
